# Hello, Rust

Your first Rust project. Four small steps:

1. Print a greeting.
2. Greet by name.
3. Count upward.
4. Add numbers.

You do not need to know any Rust syntax. Each task tells you exactly what to change, and `rustlab check` runs the compiler for you.

```text
rustlab check
```

If you are stuck, run `rustlab hint`. If you want the worked answer, run `rustlab solution`.
