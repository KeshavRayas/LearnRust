# Unit converter

A small command-line tool that converts kilometers to miles and Celsius to Fahrenheit.

You will build it in four steps:

1. Parse `"10 km"` into a value and a unit.
2. Convert between compatible units.
3. Reject bad input without panicking.
4. Wire the library into a CLI.

Run the checks from the project directory:

```text
rustlab check
```

If you get stuck, run `rustlab hint`. If you are still stuck, read the next hint with `rustlab hint --level 2`.
